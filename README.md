# AudioBrief

A powerful utility that automatically generates engaging YouTube titles and eye-catching thumbnails from audio files using AI. Perfect for podcasters, content creators, and video producers looking to streamline their workflow.

## Overview

AudioBrief analyzes your audio content and uses advanced AI models (via OpenRouter) to:
- Generate compelling, SEO-optimized YouTube titles
- Create custom thumbnail designs that capture the essence of your content
- Save time on the creative process while maintaining professional quality

## Features

- 🎵 **Audio Analysis**: Processes various audio formats to understand content context
- 🤖 **AI-Powered Generation**: Leverages OpenRouter's AI models for intelligent title and thumbnail creation
- 🎨 **Custom Thumbnails**: Generates visually appealing thumbnails tailored to your content
- 🔧 **Configurable**: Customize output style, tone, and branding preferences

## Prerequisites
- OpenRouter API key ([Get one here](https://openrouter.ai/))


AudioBrief generates:

1. **Titles**: Multiple title options 
2. **Thumbnail**: High-resolution image ready for upload
3. **Metadata**: Additional insights about your content


## Supported Audio Formats

- MP3
- WAV
- OGG
- AAC

## API Rate Limits
AudioBrief uses your OpenRouter API key, which may have rate limits depending on your plan. The tool automatically handles rate limiting and retries.
